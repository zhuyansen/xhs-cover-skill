# 规则、版式和常见错误

这些规则是从一批小红书上 AI 和工具类的高互动视频封面里归纳出来的共性，只记做法，不记具体账号。它们是经验，不是定律：拿不到封面点击率的时候，只能用自己前后几期的互动数据来验证。

## 六条规则

1. **标题占封面的两到三成。** 两行：第一行白字说主题，第二行换亮色放钩子，字号比第一行大得多（钩子只有四五个字时约为两倍）。超粗黑体、黑色粗描边、第二行略微倾斜。信息流里封面只有手机屏幕的一小块，细字等于没有字。
2. **有人像时，人占画面高度四成到一半以上，表情夸张、手在动。** 同一个账号每期用同一张脸，这是识别度的来源。没有人像也可以做，证据卡会放大补位，但有人的封面更容易被认出来。
3. **中间放「证据」，不放说明文字。** App 图标、截图、前后对比、成品缩略图、数据卡。观众不读字也该知道这期讲什么。被归纳的那批封面上是三到六样；手机上三样以内最清楚，所以这里用两到三样，脚本也最多排三张。
4. **标题里用一个数字当钩子。** 「13 个」「8/8」「180 页只看 3 章」。数字必须是内容里可核实的那个。卡片里可以有别的数字，它们是证据，不是钩子。
5. **小字越少越好。** 每张卡片上的小字不超过 10 个汉字，卡片之外不再加小字。需要凑近才能看清的字，都删掉。
6. **背景饱和、有光，颜色要少。** 深色底加辉光，或一整片纯色。除了白色，全图不超过三种颜色：标题色、标题的阴影色、最多一个警示色。

## 版式（3:4，1242×1656）

| 区域 | 位置 | 内容 |
|---|---|---|
| 标题 | 顶部约四分之一（横版没有人像时会更大） | 第一行白字约 110 像素，第二行亮色最大约 230 像素（字多会自动缩小），描边约为字号的 13%–16% |
| 证据 | 有人像：左半边中段。没有人像：横条铺满中段 | 卡片略微错开和倾斜。卡片大小由剩下的高度决定：卡片越多、加了底部问话，每张就越小 |
| 人像 | 右下，贴底 | 白色贴纸描边，带投影 |
| 底部钩子（可选） | 左下 | 色块上的一句问话，不超过 6 个字 |

脚本会自动把字缩到一行放得下。字被缩得很小，说明标题太长，该改的是字数。

## 另一种：许愿式

清单型之外的另一条路，适合「我为了解决 X，做了 Y」这类内容。

- 标题是一句愿望，不是一句描述：6 个字以内，说观众想要的结果，不说工具名。
- 人的动作就是标题的画面：标题说许愿，人就合十。
- 证据换成大家认识的 App 图标，三到五个。
- 没有任何小字，连副标题和数字都不要。

怎么选：帮人筛东西、测出结论，用清单型（两行标题、数字、证据卡）；讲自己做的东西、自己的用法，用许愿式。脚本做的是清单型；许愿式可以只写 `line1`、`line2` 加 `person`，不放 `cards`。

## 常见错误

| 错误 | 为什么不行 | 怎么改 |
|---|---|---|
| 用视频首帧当封面 | 首帧没有标题，信息流里看不出讲什么 | 每期单独做封面 |
| 让生图模型直接画整张带字带人的封面 | 中文字会错，脸会被重画成另一个人 | 模型只出底图，字和人用脚本排 |
| 标题写成内容摘要 | 太长，被缩到看不清 | 砍到两行，每行一个意思 |
| 封面上写内容里没有的数字 | 点进来发现对不上，直接走 | 只用可核实的数字 |
| 物件堆到七八个，颜色四五种 | 没有焦点 | 最多三张卡片，两三种颜色 |
| 每期换一张脸或换一种风格 | 认不出是同一个号 | 脸、字体、配色固定，只换姿势和主题色 |
| 把这张封面直接当 YouTube 缩略图 | YouTube 上字多的缩略图表现更差 | YouTube 另做一张，最多三四个字 |

## 交付前自查

- [ ] 缩到 320 像素宽，第二行大字能一眼读出来
- [ ] 标题两行，各不超过上限
- [ ] 数字来自内容本身；内容里没有数字就不写数字
- [ ] 证据一到三样，每样说一件不同的事，没有装饰凑数
- [ ] 三张图（3:4、16:9、9:16）都打开看过，没有一大块空着
- [ ] 颜色不超过三种
- [ ] 字没有压在脸上，没有出框
- [ ] 人像是用户自己的，不是从别人的内容里截的
